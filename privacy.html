Política de privacidad de vira

vira es una aplicación de uso personal. Solo accede a los canales de YouTube de su propietario, con su autorización expresa mediante Google OAuth.

Qué datos usa: los datos de los canales autorizados (vídeos, estadísticas y analítica de YouTube) para subir vídeos y medir su rendimiento.

Dónde se guardan: únicamente en el ordenador del propietario. No se venden, no se comparten con terceros y no se usan para publicidad.

Cómo revocar el acceso: en cualquier momento desde https://myaccount.google.com/permissions.

El uso de los datos obtenidos de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.
