Política de privacidad de vira

Última actualización: 8 de octubre de 2026.

Qué es vira

vira es una aplicación de escritorio de uso personal. Solo la utiliza su propietario y solo accede a los canales de YouTube de su propietario, con su autorización expresa mediante Google OAuth.

Servicios de la API de YouTube

vira usa los servicios de la API de YouTube (YouTube API Services). Al usar vira aceptas las Condiciones del servicio de YouTube. Los datos se tratan también según la Política de privacidad de Google.

Qué datos usa y para qué

Con tu autorización, vira accede a: los datos básicos del canal (identificador y nombre), los vídeos que sube vira y las estadísticas y la analítica de YouTube de esos vídeos (visualizaciones, tiempo de visualización, retención, suscriptores ganados). Los usa solo para subir los vídeos que apruebas y medir su rendimiento.

Dónde se guardan y con quién se comparten

Los datos y los tokens de acceso se guardan únicamente en el ordenador del propietario. No se venden, no se comparten con terceros y no se usan para publicidad. vira no usa cookies ni recoge datos de otras personas.

Conservación y borrado

Las estadísticas se conservan mientras se usa vira para medir los vídeos. Puedes pedir el borrado de todos los datos escribiendo a viraesviral01@gmail.com; se borran en un plazo máximo de 7 días. Si revocas el acceso, vira deja de acceder a tu cuenta inmediatamente y los datos guardados se borran en un plazo máximo de 7 días.

Cómo revocar el acceso

En cualquier momento desde la página de permisos de tu cuenta de Google: https://security.google.com/settings/security/permissions.

El uso de los datos obtenidos de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.
